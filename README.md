# CSE676 Deep Learning — Summer 2024

Deep learning coursework from the University at Buffalo's graduate CS program (CSE 676).

## Topics Covered

- Convolutional Neural Networks (CNNs) for image classification
- Recurrent Neural Networks (RNNs) and LSTMs for sequence modeling
- Transfer learning with pretrained models (ResNet, VGG, etc.)
- Training optimization: batch norm, dropout, learning rate scheduling
- PyTorch and TensorFlow implementations
